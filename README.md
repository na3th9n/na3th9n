#### Workout Tracker (Oct 2026)

I love using [HEVY](https://hevy.com/) which is an app that helps me track my workouts with a social media aspect to it. However, there is a paywall for how much data they'll display for you which is 3 months and I've been using the app for more than a year. Their public API is also blocked by the paywall.

However, they do let you export all your data as a CSV. Therefore, the purpose of this project is to to have a CSV parser that will save all my workout data within a database, and have a full-stack app that will let me track and visualize my gym progress. The larger objective is to then replace Hevy with my own created app. 

I am using this project to remove the rust I have on fullstack development and to learn more, so **none of the code is AI generated or assisted!!**. I believe using AI tooling is great and it is what I use on my other projects. However, I do believe it is also beneficial to code manually for the sake of learning.
